1.1 Matrices

  • A matrix is a rectangular arrangement of numbers in rows and columns.
  • Each number in a matrix is called an element.
  • A matrix is represented by capital letters such as A, B, C.

Example:

A = 2345
  • Order of matrix = Number of rows × Number of columns.
  • Above matrix has order 2 × 2.

Types of matrices

TypeMeaning
Row matrixOnly one row
Column matrixOnly one column
Square matrixRows = Columns
Rectangular matrixRows ≠ Columns
Zero matrixAll elements are zero
Diagonal matrixAll non-diagonal elements are zero
Scalar matrixDiagonal elements are equal
Identity matrixDiagonal elements are 1, others 0
Symmetric matrixAT = A
Skew-symmetric matrixAT = −A

Identity matrix:

I = 1001
Remember: Identity matrix behaves like number 1 in matrix multiplication.

1.2 Matrix Operations

1. Addition and subtraction

  • Matrices must have the same order.
  • Add or subtract corresponding elements.
A + B = abcd + efgh
= a + eb + fc + gd + h

2. Scalar multiplication

  • Multiply every element by the given number.
kA = kakbkckd

3. Matrix multiplication

  • Number of columns of first matrix must equal number of rows of second matrix.
  • Multiply rows of first matrix by columns of second matrix.
  • Generally, matrix multiplication is not commutative.
AB ≠ BA

4. Transpose of a matrix

  • Interchange rows and columns.
  • Represented by AT.
A = 1234     AT = 1324

Important properties:

  • (AT)T = A
  • (A + B)T = AT + BT
  • (AB)T = BTAT

1.3 Determinants

  • A determinant is a numerical value associated with a square matrix.
  • Represented by |A| or det(A).
  • Used to solve simultaneous equations and find matrix inverses.

Determinant of 2 × 2 matrix

A = abcd
|A| = abcd = ad − bc

Example

A = 2345
|A| = (2 × 5) − (3 × 4)
= 10 − 12 = −2

Determinant of 3 × 3 matrix

A = abc def ghi
|A| = a(ei − fh) − b(di − fg) + c(dh − eg)

Important properties

  • Interchanging two rows changes the sign of determinant.
  • If two rows are identical, determinant = 0.
  • If one row is entirely zero, determinant = 0.
  • Determinant of identity matrix = 1.
  • Determinant of triangular matrix = Product of diagonal elements.
  • |AB| = |A||B|.
  • |AT| = |A|.
Remember:
|A| = 0 → Matrix is singular.
|A| ≠ 0 → Matrix is non-singular.

1.4 Inverse of a Matrix

  • Inverse of matrix A is represented by A−1.
  • It exists only when determinant is non-zero.
AA−1 = I

For a 2 × 2 matrix:

A = abcd
A−1 = 1ad − bc d−b−ca
Remember the shortcut:
  1. Interchange diagonal elements.
  2. Change signs of other two elements.
  3. Divide by determinant.

1.5 Simultaneous Linear Equations

  • Simultaneous equations are two or more equations containing common unknown variables.
  • They must be solved together to find the unknown values.

Example

2x + y = 5
x + y = 3

Subtract second equation from first:

x = 2

Substitute:

2 + y = 3
y = 1

Matrix method

A system of equations can be represented as:

AX = B

Where:

  • A = Coefficient matrix
  • X = Unknown variable matrix
  • B = Constant matrix

Solution:

X = A−1B

This method works when A is square and non-singular.

Cramer's Rule

For two equations:

a1x + b1y = c1
a2x + b2y = c2

Main determinant:

D = a1b1a2b2
Dx = c1b1c2b2     Dy = a1c1a2c2
x = DxD     y = DyD

Valid for a unique solution when D ≠ 0.

2.1 Introduction to Vectors

  • A vector is a quantity having both magnitude and direction.
  • Represented by a bold letter or an arrow above the letter.
  • Examples: Force, velocity, acceleration and displacement.

Scalar vs Vector

ScalarVector
Magnitude onlyMagnitude and direction
MassForce
TemperatureVelocity
TimeAcceleration
EnergyDisplacement
SpeedMomentum

2.2 Types of Vectors

  • Zero vector: Magnitude is zero.
  • Unit vector: Magnitude is 1.
  • Equal vectors: Same magnitude and direction.
  • Negative vectors: Same magnitude but opposite directions.
  • Parallel vectors: Act along parallel directions.
  • Position vector: Specifies the position of a point from the origin.
  • Like vectors: Same direction.
  • Unlike vectors: Opposite directions.

2.3 Vector Representation

A vector in three dimensions:

A = Axî + Ayĵ + Azk̂

Where:

  • î = Unit vector along X-axis.
  • ĵ = Unit vector along Y-axis.
  • k̂ = Unit vector along Z-axis.

Magnitude:

|A| = √Ax² + Ay² + Az²

Example

A = 3î + 4ĵ
|A| = √3² + 4² = 5

2.4 Unit Vector

  • A unit vector has magnitude equal to 1.
  • It represents direction only.
Â = A|A|

Example

A = 3î + 4ĵ
Â = 35 î + 45 ĵ

2.5 Vector Addition and Subtraction

Addition

  • Add corresponding components.
A + B

If:

A = 2î + 3ĵ
B = 4î + 5ĵ

Then:

A + B = 6î + 8ĵ

Subtraction

A − B
= (Ax − Bx)î + (Ay − By)ĵ
Remember: Vector addition follows the triangle law and parallelogram law.

2.6 Dot Product (Scalar Product)

  • Dot product produces a scalar quantity.
  • Used to calculate work done and angle between vectors.
A · B = AB cos θ

In component form:

A · B = AxBx + AyBy + AzBz

Where θ is the angle between vectors.

Important cases

AngleDot product
0°Maximum positive, AB
90°Zero
180°Maximum negative, −AB
  • If dot product = 0, vectors are perpendicular (for non-zero vectors).

Mechanical application: Work done

W = F · s
W = Fs cos θ

Where F = Force and s = Displacement.

2.7 Cross Product (Vector Product)

  • Cross product produces a vector.
  • Direction is perpendicular to both original vectors.
  • Used in torque and angular momentum calculations.
|A × B| = AB sin θ

Component form:

A × B = îĵk̂ AxAyAz BxByBz

Important cases

  • At 0°: Cross product = 0.
  • At 90°: Maximum magnitude = AB.
  • At 180°: Cross product = 0.

Mechanical application: Torque

T = r × F

Magnitude:

T = rF sin θ

Difference between dot and cross product

Dot productCross product
Scalar resultVector result
Uses cos θUses sin θ
Measures parallel componentMeasures perpendicular component
Work doneTorque

2.8 Important Vector Identities

  • A · B = B · A
  • A × B = −(B × A)
  • A × A = 0
  • A · A = |A|²
  • Cross product of parallel vectors = 0.
  • Dot product of perpendicular vectors = 0.

3.1 Numerical Methods

  • Numerical methods are mathematical techniques used to obtain approximate solutions.
  • Used when exact mathematical solutions are difficult or impossible.
  • Common in engineering calculations, experiments and machine performance analysis.

Examples:

  • Calculating area under a curve.
  • Estimating temperature between measured points.
  • Calculating engine performance from experimental data.

3.2 Numerical Integration

  • Integration calculates the area under a curve.
  • Numerical integration estimates the area using a finite number of data points.
  • Useful when the function is complicated or only experimental data is available.

A. Trapezoidal Rule

  • Divides the area under a curve into trapezoids.
  • Straight lines connect consecutive data points.
  • Simple method but generally less accurate than Simpson's rule for smooth curved functions.

For one interval:

A = h2 (y0 + y1)

For multiple equal intervals:

I = h2 [ y0 + yn + 2(y1 + y2 + ⋯ + yn−1) ]

Where:

  • h = Equal interval width.
  • n = Number of intervals.
  • y = Function values at data points.

Interval width:

h = b − an
Remember: Trapezoidal rule = Average of parallel sides × Width.

B. Simpson's 1/3 Rule

  • Approximates the curve using parabolic segments.
  • Generally more accurate than trapezoidal rule for smooth functions.
  • Requires an even number of intervals.

Formula:

I = h3 [ y0 + yn + 4(y1 + y3 + ⋯ + yn−1) + 2(y2 + y4 + ⋯ + yn−2) ]

Coefficient pattern

1, 4, 2, 4, 2, 4, …, 2, 4, 1
Remember:
  • First and last coefficients = 1.
  • Odd-indexed interior points = 4.
  • Even-indexed interior points = 2.

C. Simpson's 3/8 Rule

  • Uses cubic polynomial approximation.
  • Requires the number of intervals to be a multiple of 3.

Formula:

I = 3h8 [ y0 + yn + 3(other terms except multiples of 3) + 2(interior terms at multiples of 3) ]

Coefficient pattern

1, 3, 3, 2, 3, 3, 2, …, 3, 3, 1

Comparison

MethodApproximationRequirement
TrapezoidalStraight linesAny number of intervals
Simpson's 1/3ParabolasEven number of intervals
Simpson's 3/8Cubic curvesIntervals multiple of 3

3.3 Numerical Interpolation

  • Interpolation estimates an unknown value between known data points.
  • It is used when the required value lies within the available data range.
  • Extrapolation estimates values outside the known data range.

Example

Temperature (°C)Pressure (bar)
202
304
406

Pressure at 25°C:

P = 3 bar

This is linear interpolation.

A. Linear Interpolation

Used when data points are approximately on a straight line.

y = y1 + x − x1x2 − x1 (y2 − y1)

Where:

  • x1, y1 = First known point.
  • x2, y2 = Second known point.
  • x = Required value.
  • y = Estimated value.

B. Newton's Forward Interpolation

  • Used when data points are equally spaced.
  • Best suited when the required value is near the beginning of the table.
y = y0 + uΔy0 + u(u − 1)2! Δ²y0 + ⋯

Where:

u = x − x0h
  • Δy = First forward difference.
  • Δ²y = Second forward difference.

C. Newton's Backward Interpolation

  • Used when data points are equally spaced.
  • Best suited when the required value is near the end of the table.
y = yn + u∇yn + u(u + 1)2! ∇²yn + ⋯

Where:

u = x − xnh
  • ∇y = First backward difference.
  • ∇²y = Second backward difference.
Remember:
  • Forward interpolation → Near beginning.
  • Backward interpolation → Near end.
  • Linear interpolation → Straight-line approximation.
  • Interpolation → Inside known range.
  • Extrapolation → Outside known range.

4.1 Errors in Measurements

  • Error is the difference between measured value and true or accepted value.
  • No measurement is perfectly accurate.
  • Errors occur due to instruments, human observations and environmental conditions.

Types of errors

ErrorMeaning
Systematic errorConsistent error due to instrument or method
Random errorUnpredictable variation in measurements
Gross errorHuman mistakes or incorrect readings
Absolute errorMagnitude of difference
Relative errorAbsolute error divided by true value
Percentage errorRelative error × 100

4.2 Absolute Error

Ea = |Xt − Xm|

Where:

  • Xt = True or accepted value.
  • Xm = Measured value.

Example

True value = 100 mm

Measured value = 98 mm

Ea = |100 − 98| = 2 mm

4.3 Relative Error

Er = Absolute ErrorTrue Value
Er = 2100 = 0.02

4.4 Percentage Error

Ep = Absolute ErrorTrue Value × 100
Ep = 2100 × 100 = 2%
Remember:
  • Absolute error → Actual difference.
  • Relative error → Error compared with true value.
  • Percentage error → Error expressed in percentage.

4.5 Significant Figures

  • Significant figures are the meaningful digits in a measured number.
  • They indicate the precision of a measurement.

Rules for significant figures

  1. All non-zero digits are significant.
    • 234 = 3 significant figures.
  2. Zeros between non-zero digits are significant.
    • 1005 = 4 significant figures.
  3. Leading zeros are not significant.
    • 0.0045 = 2 significant figures.
  4. Trailing zeros after a decimal point are significant.
    • 2.500 = 4 significant figures.
  5. Trailing zeros in whole numbers without a decimal point may be ambiguous.
    • 1500 has an unclear number of significant figures unless scientific notation is used.

Examples

NumberSignificant figures
45.63
0.00522
3.0404
120.04
0.000812
50064

4.6 Rounding Off

  • If the next digit is less than 5, leave the previous digit unchanged.
  • If the next digit is greater than 5, increase the previous digit by 1.
  • If the next digit is exactly 5, follow the specified rounding convention. In the common school convention, increase the previous digit by 1.

Examples

  • 4.32 to 2 significant figures = 4.3
  • 4.38 to 2 significant figures = 4.4
  • 15.678 to 3 significant figures = 15.7

4.7 Accuracy vs Precision

AccuracyPrecision
Closeness to true valueCloseness of repeated readings to each other
Indicates correctnessIndicates repeatability
Affected by systematic errorsAffected by random errors
Remember:
  • Accuracy = How close to the correct answer?
  • Precision = How consistent are the readings?

4.8 Error Propagation

When measurements are used in calculations, errors can affect the final result.

Addition and subtraction

For independent maximum absolute uncertainties:

ΔQ = ΔA + ΔB

Multiplication

For maximum relative uncertainties:

ΔQQ ≈ ΔAA + ΔBB

Division

ΔQQ ≈ ΔAA + ΔBB

Powers

If:

Q = An

Then:

ΔQQ ≈ |n| ΔAA
Note: These are approximate maximum-error rules for small uncertainties.
