1.1 Limits

  • A limit is the value that a function approaches as the independent variable approaches a particular value.
  • It describes the behaviour of a function near a point.

Notation

limx→a f(x) = L

Meaning: As x approaches a, f(x) approaches L.

Important types of limits

  • Left-hand limit (LHL): x approaches a value from the left.
  • Right-hand limit (RHL): x approaches a value from the right.
  • Infinite limit: Function approaches infinity.
  • Limit at infinity: Behaviour of a function as x approaches infinity.

Condition for existence of limit

LHL = RHL

1.3 Continuity

A function is continuous at x = a if there is no break, jump or hole in its graph at that point.

Three conditions for continuity

  1. f(a) must exist.
  2. limx→a f(x) must exist.
  3. limx→a f(x) = f(a).

Types of discontinuity

  • Removable: A hole in the graph.
  • Jump: Left and right limits are different.
  • Infinite: Function approaches infinity near a point.

Remember

  • Differentiability implies continuity.
  • Continuity does not necessarily imply differentiability.

Mechanical Engineering Application

  • Studying continuous changes in velocity, temperature and pressure.
  • Analysing sensor readings and physical quantities near a particular operating condition.

2.1 Differentiation

  • Differentiation measures the rate of change of one quantity with respect to another.
  • It gives the slope of a curve at a particular point.
  • It is used to calculate velocity, acceleration and changing engineering parameters.

Notation

dydx = f ′(x)

If y is displacement:

  • First derivative = Velocity.
  • Second derivative = Acceleration.
  • Third derivative = Jerk.
v = dsdt
a = d²sdt²

2.3 Rules of Differentiation

1. Sum Rule

Differentiate each term separately.

ddx (u + v) = u′ + v′

2. Product Rule

When two functions are multiplied:

ddx (u v) = u′v + u v′

3. Quotient Rule

When one function is divided by another:

ddx ( uv ) = v u′ − u v′v²

4. Power Rule

ddx (xn) = n xn−1

2.4 Partial Differentiation

  • Used when a function contains two or more independent variables.
  • Differentiate with respect to one variable while keeping all other variables constant.

Example

z = x² + 3xy + y²

Partial derivative with respect to x:

∂z∂x = 2x + 3y

Partial derivative with respect to y:

∂z∂y = 3x + 2y
Important symbol:
Ordinary differentiation: d
Partial differentiation: ∂

Mechanical Engineering Application

Suppose gas pressure depends on temperature and volume:

P = f(T, V)

Then:

∂P∂T

represents the rate of change of pressure with temperature while volume remains constant.

∂P∂V

represents the rate of change of pressure with volume while temperature remains constant.

2.5 Chain Rule

  • Used when one function depends on another function.
  • Helps differentiate composite functions.

If:

y = f(u),    u = g(x)

Then:

dydx = dydu × dudx

Example

y = (3x + 2)4

Let u = 3x + 2.

dydx = 4(3x + 2)3 × 3
dydx = 12(3x + 2)3

Remember

  • Differentiate the outer function first, then multiply by the derivative of the inner function.

3.1 Basic Concept

  • Maxima: Highest value of a function.
  • Minima: Lowest value of a function.
  • Used to find optimum values of engineering parameters.

3.2 First Derivative Test

For a function y = f(x):

  1. Find the first derivative.
  2. Put the first derivative equal to zero.
  3. Find the critical points.
  4. Check the sign of the first derivative around each point.
dydx = 0
Sign changeResult
Positive to negativeMaximum
Negative to positiveMinimum
No sign changeNeither maximum nor minimum

3.3 Second Derivative Test

First, find:

dydx = 0

Then calculate:

d²ydx²
Second derivativeResult
f ″(x) < 0Maximum
f ″(x) > 0Minimum
f ″(x) = 0Test is inconclusive

Example

y = x² − 4x + 5

First derivative:

dydx = 2x − 4

Put equal to zero:

2x − 4 = 0  ⇒  x = 2

Second derivative:

d²ydx² = 2

Since 2 > 0, the function has a minimum at x = 2.

Minimum value:

y = 2² − 4(2) + 5 = 1
Minimum value = 1 at x = 2

3.4 Engineering Applications

Applications

  • Finding maximum engine efficiency.
  • Minimising fuel consumption.
  • Minimising material usage and manufacturing costs.
  • Optimising ship speed and power consumption.
  • Finding maximum load capacity under constraints.

Remember

  • First derivative identifies stationary points; second derivative helps classify them.

4.1 Integration

  • Integration is the reverse process of differentiation.
  • It is used to calculate accumulated quantities.
  • It can calculate area under a curve, displacement, work and other physical quantities.

Notation

∫ f(x) dx

4.2 Indefinite Integration

  • Does not have fixed upper and lower limits.
  • Gives a general function.
  • Always includes an integration constant C.

Basic Formula

∫ xn dx = xn+1n + 1 + C

Where n ≠ −1.

4.4 Methods of Integration

1. Direct Integration

Apply standard integration formulas.

Example

∫ 3x² dx = x³ + C

2. Substitution Method

Used when a function and its derivative appear together.

Example

∫ 2x (x² + 1)³ dx

Let u = x² + 1, then du = 2x dx.

= ∫ u³ du
= u⁴4 + C
= (x² + 1)⁴4 + C

3. Integration by Parts

Used when two different functions are multiplied.

∫ u dv = u v − ∫ v du
Remember the LIATE rule for choosing u:
  • L – Logarithmic
  • I – Inverse trigonometric
  • A – Algebraic
  • T – Trigonometric
  • E – Exponential

  • Displacement from velocity.

5.1 Differential Equations

  • An equation containing derivatives of an unknown function.
  • Describes how physical quantities change with respect to time or another variable.
  • Widely used in mechanical and marine engineering.

Example

dydx + y = 0

This is a differential equation.

5.2 Order of Differential Equation

The order is determined by the highest-order derivative present.

EquationOrder
dydx + y = 0 First order
d²ydx² + y = 0 Second order
d³ydx³ + y = 0 Third order

Remember

  • Highest derivative determines the order.

5.3 First-Order Differential Equations

A first-order differential equation contains only the first derivative as its highest derivative.

General form

dydx = f(x, y)

Separable Variable Method

If:

dydx = g(x) h(y)

Separate variables:

dyh(y) = g(x) dx

Then integrate both sides.

Example

dydx = 2x

Separate and integrate:

dy = 2x dx
y = x² + C

Linear First-Order Differential Equation

General form:

dydx + P y = Q

Where P and Q may be functions of x.

Integrating factor:

IF = e∫ P dx

Solution:

y (IF) = ∫ Q (IF) dx + C

5.4 Second-Order Differential Equations

  • Contains the second derivative as its highest derivative.
  • Commonly used to describe acceleration, vibration and oscillations.

General form

d²ydx² + a dydx + b y = 0

Auxiliary Equation Method

Assume:

y = emx

Then form the auxiliary equation:

m² + a m + b = 0

Solve for m.

Three Cases

RootsGeneral solution
Two distinct real roots m₁, m₂ y = C₁em₁x + C₂em₂x
Equal real roots m, m y = (C₁ + C₂x) emx
Complex roots α ± iβ y = eαx (C₁ cos βx + C₂ sin βx)

5.5 Mechanical and Marine Engineering Applications

Applications

  • Engine vibration analysis.
  • Piston and crankshaft motion.
  • Ship propulsion system dynamics.
  • Cooling and heating systems.
  • Fluid flow and pressure changes.
  • Temperature variation in machinery.
  • Spring-mass-damper systems.

Example – Simple Harmonic Motion

d²xdt² + ω² x = 0

Where

  • x = Displacement
  • ω = Angular frequency
  • t = Time

General solution:

x = A cos ωt + B sin ωt

This equation is useful for understanding oscillatory motion and mechanical vibrations.

Maxima and Minima

Key points

  • f ′(x) = 0: Find stationary points.
  • f ″(x) > 0: Minimum.
  • f ″(x) < 0: Maximum.

Key points

  • Second order: Highest derivative is second derivative.
  • First-order linear equation: y′ + P y = Q.

  • Second-order auxiliary equation: m² + a m + b = 0.

10 Must-Remember Concepts

  1. Limit exists when LHL = RHL.
  2. Continuity requires f(a) = limx→a f(x).
  3. Differentiation gives rate of change.
  4. Integration is the reverse process of differentiation.
  5. Derivative of a constant is zero.
  6. Derivative of xn is n xn−1.
  7. Chain rule is used for composite functions.
  8. Second derivative identifies maxima and minima in standard cases.
  9. Definite integration gives a numerical result.
  10. Order of a differential equation depends on its highest derivative.
