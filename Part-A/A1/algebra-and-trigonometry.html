1.1 Basic Algebraic Equations

  • An algebraic equation is a mathematical statement containing variables and constants.
  • The highest power of the variable determines the degree of the equation.
EquationDegreeType
2x + 5 = 151Linear
x² + 5x + 6 = 02Quadratic
x³ + 2x + 1 = 03Cubic

Important rules

  • Whatever operation is performed on one side must also be performed on the other side.
  • When shifting a term across the equal sign, its sign changes.
  • Always simplify brackets before solving.
  • Check the final answer by substituting it into the original equation.

1.2 Quadratic Equations

A quadratic equation is an equation of degree 2.

Standard form

ax² + bx + c = 0

Where

  • a = coefficient of x²
  • b = coefficient of x
  • c = constant
  • a ≠ 0

Quadratic formula

x = −b ± √b² − 4ac2a

Discriminant

D = b² − 4ac

The discriminant determines the nature of roots.

DiscriminantNature of roots
D > 0Two distinct real roots
D = 0Two equal real roots
D < 0Two complex roots

Important relationships between roots

If roots are α and β:

α + β = − ba
αβ = ca

Example

Solve:

x² − 5x + 6 = 0

Factorisation:

(x − 2)(x − 3) = 0

Therefore:

x = 2,   x = 3

Engineering application

  • Calculating projectile motion.
  • Finding unknown dimensions.
  • Solving equations involving acceleration and displacement.
  • Determining operating conditions in engineering systems.

1.3 Simultaneous Equations

  • Two or more equations containing multiple unknown variables are called simultaneous equations.
  • The solution must satisfy all equations simultaneously.

Example

2x + y = 10
x + y = 6

Subtracting the second equation from the first:

x = 4

Substitute into the second equation:

4 + y = 6
x = 4,   y = 2

Methods of solving

  1. Substitution method – find one variable and substitute it into another equation.
  2. Elimination method – eliminate one variable by addition or subtraction.
  3. Matrix method – solve using matrices and determinants.

Engineering applications

  • Calculating forces in mechanical systems.
  • Finding current and voltage in electrical circuits.
  • Solving flow equations.
  • Determining unknown loads and reactions.

2.1 Indices (Exponents)

An index represents the power to which a number is raised.

Example

2³ = 2 × 2 × 2 = 8

Important laws of indices

RuleFormula
Multiplicationam × an = am+n
Divisionam / an = am−n
Power of a power(am)n = amn
Zero powera0 = 1
Negative powera−n = 1 / an
Fractional powera1/n = n√a

Remember

  • Any non-zero number raised to zero is 1.
  • A negative exponent means reciprocal.
  • A fractional exponent represents a root.

2.2 Logarithms

A logarithm is the inverse operation of exponentiation.

ax = N

Can be written as:

loga N = x

Example

2³ = 8

Therefore:

log2 8 = 3

Important logarithm laws

RuleFormula
Productloga(MN) = logaM + logaN
Divisionloga(M/N) = logaM − logaN
Powerloga(Mn) = n logaM
Log of 1loga1 = 0
Log of baselogaa = 1

Two commonly used logarithms

  • Common logarithm: Base 10, written as log10.
  • Natural logarithm: Base e, written as ln.
  • e ≈ 2.71828

Change of base formula

2.3 Exponential Functions

  • An exponential function contains a variable in the exponent.

General form:

y = ax
  • Exponential growth: Quantity increases with time.
  • Exponential decay: Quantity decreases with time.

Important formula

N = N0 ekt

Where

  • N0 = initial quantity.
  • N = final quantity.
  • k = growth or decay constant.
  • t = time.

Engineering applications

  • Cooling of machinery and engine components.
  • Temperature changes.
  • Battery discharge.
  • Radioactive decay.
  • Pressure and thermal system calculations.

FunctionMeaning

These rules are used to solve non-right-angled triangles. They are useful when the triangle does not contain a 90° angle.

4.1 Sine Rule

The sine rule relates the sides of a triangle to their opposite angles.

The mathematical relationship is:

asin A = bsin B = csin C

Where

  • a, b, c = sides of the triangle.
  • A, B, C = opposite angles.

When to use

  • When two angles and one side are known.
  • When two sides and a non-included opposite angle are known.

Example

Given: A = 30°, B = 60°, a = 10 m. Find side b.

10sin 30° = bsin 60°
b = 10 × 0.8660.5
b = 17.32 m

4.2 Cosine Rule

The cosine rule is an extension of the Pythagoras theorem for non-right-angled triangles.

Formula

c² = a² + b² − 2ab cos C

Similarly

a² = b² + c² − 2bc cos A
b² = a² + c² − 2ac cos B

When to use

  • When two sides and the included angle are known.
  • When all three sides are known and an angle is required.

Example

Given: a = 3 m, b = 4 m, C = 90°. Find c.

c² = 3² + 4² − 2(3)(4) cos 90°
c² = 9 + 16 = 25
c = 5 m
Remember: When the included angle is 90°, the cosine rule becomes the Pythagoras theorem.
